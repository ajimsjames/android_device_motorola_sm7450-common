# Motorola SM7450 Common Device Tree

Common device tree source for Motorola SM7450 (Snapdragon 7s Gen 2) platform devices for LineageOS / Android 16 (`lineage-23.2`).

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| **Chipset** | Qualcomm SM7450 (Snapdragon 7s Gen 2) |
| **CPU** | Octa-core (4x2.40 GHz Cortex-A78 & 4x1.95 GHz Cortex-A55) |
| **GPU** | Adreno 710 |
| **Architecture** | ARM64 |
